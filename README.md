# Week 4: Machine Learning Model Development and Evaluation

Task: classify breast tumours as malignant or benign (malignant = positive class).
Dataset: Breast Cancer Wisconsin (Diagnostic), UCI ML Repository (via scikit-learn).

- `Week4_ML_Model_Report.docx` – full report
- `week4_ml_model.ipynb` – notebook
- `week4_model.py` – script (pipeline, Logistic Regression, Decision Tree, Random Forest, evaluation, error analysis)
- `m1_confusion.png` to `m6_threshold.png` – figures, `model_results.csv` – metrics table

## Run
```
pip install pandas numpy matplotlib seaborn scikit-learn
mkdir w4figs
python week4_model.py
```
